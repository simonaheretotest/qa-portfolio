| Project | Type | Tools |
|---|---|---|
| [Valentino's Coffee API tests](postman/) | API testing | Postman, Postman CLI, GitHub Actions |

## How the tests run

The API tests run automatically in **GitHub Actions** on every push to `main`, using **Postman CLI**.
The workflow file is in [`.github/workflows/postman.yml`](../.github/workflows/postman.yml).
